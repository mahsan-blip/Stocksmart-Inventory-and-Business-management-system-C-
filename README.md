# Stocksmart : Inventory and Business Management System

A concole based Inventory and Business Managemnt system built in C++.

| Features | Function Name | Description |
|---|---|---|
| Add Product | addproduct() | User can add product from here|
| View all Products | displayproduct() | User can View all products from here|
| Search Product | displaysearchedproduct() | User can search and view the product from here|
| Update Product | updateproducts() | User can update product from here|
| Add new stock | restockproducts() | User can also add new stock from here|
| Sell product | sellproduct() | User can also sell product from here and all saling record will be save along with this print customers bill |
| Delete product | deleteproduct() | User can also delete product from here |
| View all sales | displaysales() | User can View all sales from here|
| Low stock report | lowstockreport() | User can also view low quantity stocks by setting threshold by his own choice but by default it is 5|
| sales report | salesreport() | User can view the sales report from here|
| Business analytics | businesnanlytics() | User can viea the record of the stock which is  currently present|
| Top selling products | topsellingproducts() | User can also view the top 3 profitable products|
